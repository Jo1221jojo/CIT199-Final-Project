#Contact Manager Final Project
#This project is a contact manager program written in Python. The program allows users to add, view, search, and delete contacts using a SQLite database.

#Features
- Add contacts
- View all contacts
- Search for contacts
- Delete contacts
- Store data using SQLite

#Requirements
#Python 3
#sqlite3 library

#How to run program
1. Open the project in PyCharm
2. Run contact_manager.py
3. Use the menu options to manage contacts

#Reflection
#One advantage of using a database is that it keeps data organized and easier to search.
#Working with SQLite was new to me because I learned how to create tables and store data using SQL commands in Python.
#I would probably use a database in future projects because it makes managing data more organized and easier to understand.
